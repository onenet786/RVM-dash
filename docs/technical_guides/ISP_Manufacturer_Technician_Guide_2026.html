Manufacturer Technician Guide

Full engineering hotkey, diagnostics, serial safety, recovery and deployment reference for RVMDesktopApp and PecoDropDesktopApp

ISP-AUTHORIZED MANUFACTURER TECHNICIANS ONLY. Direct servo and system-power controls must not be distributed to public users.
Products: Public RVM and Enterprise PecoDrop
Platform: .NET 8 WPF / Windows kiosk
Edition: 1 October 2026

1. Product boundary and safety

ProductPathIdentity
Public RVMRVMDesktopAppPlastic, cans, UBC and rejects; public rewards and leaderboards.
Enterprise PecoDropPecoDropDesktopAppDual landscape displays, QR/keypad, ⭕ plastic, 🔺 metal/cans and 🟦 weighed paper.
Never mix: machine IDs, serial ports, configuration, ads, organization bindings, credentials, logs or databases. Isolate public access and moving mechanisms before service.
  • Use lockout/tagout for mains, motors and cabinet work.
  • Keep hands, tools and items clear before any gate command.
  • Only one process may own the serial port; AdminWindow reuses the kiosk connection.
  • Log command, result, machine ID and final safe state.

7. Arduino host safety and calibration

Firmware boot → HOST:WAITING
Desktop connects → renew HOST:ALIVE
Desktop authorizes → HOST:START
Calibration request/retry → CALIBRATION:OK
Verified compartment query → intake enabled
No host lease for 5 seconds → safe closed state
  • Firmware: PecoDropDesktopApp/Arduino/RVM_Arduino/RVM_Arduino.ino.
  • Target Arduino Mega 2560 / ATmega2560.
  • Close PecoDrop before firmware upload.
  • After hot-plug/relaunch, reconnect, calibrate and verify state before intake.
  • stk500v2_getsync() is a port/bootloader/upload-path problem, not sketch-size failure.

9. Build, data and deployment

dotnet publish .\RVMDesktopApp\RVMDesktopApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false
dotnet publish .\PecoDropDesktopApp\PecoDropDesktopApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false
  • Never compile Debug builds on production kiosks.
  • Use fixed signed paths, separate ProgramData folders and bounded watchdog recovery.
  • PostgreSQL rvmpg is the production source of truth.
  • MongoDB is read-only/sync-only: never add, edit, update or delete there.
  • Never put passwords or tokens in documentation.

10. Return-to-service checklist

  • Cabinet closed; tools removed.
  • All gates/irises physically closed.
  • Correct app and machine ID.
  • Demo Mode closed.
  • Single stable serial connection.
  • Calibration successful.
  • Compartment states verified.
  • Displays/touch mapping correct.
  • API/DB and offline queue checked.
  • Controlled acceptance/rejection test passed.
  • Reward record verified without duplication.
  • Service log completed.
