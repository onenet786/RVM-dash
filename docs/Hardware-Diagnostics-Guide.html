RVM & PecoDrop Hardware Diagnostics

Implementation and troubleshooting guide
Generated 5 October 2026

Architecture: The public RVM and enterprise PecoDrop remain independent applications with separate firmware and protocols. Admin tests reuse the kiosk's active serial connection; they never open a competing COM port.

Safety rules

  • Manual actuator tests stop normal intake.
  • RVM gates auto-close after three seconds. Only one gate is opened at a time.
  • PecoDrop retains its five-second host lease, close/detach behavior, and SERVO:ALL:CLOSE shutdown.
  • Closing Admin returns hardware to a safe state.
  • Servo status means commanded position. Physical position is not verified because no limit-switch feedback is installed.

Admin workflow

  1. Open Admin while the kiosk owns the Arduino connection.
  2. Confirm the green connected status.
  3. Select Refresh All and inspect timestamped RX output.
  4. Activate each sensor physically and refresh again; compare raw and interpreted states.
  5. Run calibration only with all apertures/chambers empty.
  6. Run one actuator at a time while personnel remain clear.
  7. Use CLOSE ALL / Safe Stop before leaving Admin.
  8. Save the console text with the machine ID and firmware version in the maintenance record.

Acceptance checklist

  • Correct firmware identity; no wrong-app protocol.
  • No second COM connection is created.
  • Every sensor changes state or returns a valid distance.
  • Every commanded servo moves in the correct direction and safely closes.
  • Disconnecting USB or expiring the PecoDrop lease closes actuators.
  • Normal PLASTIC/CAN/UBC/REJECT flow works after RVM diagnostics.
  • Normal PecoDrop circle/triangle/square workflow works after diagnostics.
