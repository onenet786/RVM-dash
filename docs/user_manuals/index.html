SYSTEM PecoDrop RVM Exterior Architecture & Intake Ports

The PecoDrop Reverse Vending Machine utilizes a high-efficiency 3-stream mechanical layout designed for intuitive recycling, rapid throughput, and high-accuracy verification.

Figure 1.1: 3D CAD Master Rendering of PecoDrop 3-Chamber Smart Kiosk Click to Enlarge

Chamber 1: PET Plastic

3-tier vertical ultrasonic array (HC-SR04) scans bottle height in centimeters to classify containers as Small (≤250ml), Medium (500ml), or Large (1.5L+).

Chamber 2: Aluminum Cans

High-frequency inductive proximity sensor executes a 12-sample burst over 180ms. Must register ≥9 Active LOW readings to confirm 100% genuine beverage can metal.

Chamber 3: Paper Wastage

Dual ultrasonic sensors verify arrival on weighing tray. 24-bit HX711 ADC samples load cell platform with 420 counts/gram precision tare calibration.

Inbound Commands Reference

Command Target State Description Firmware Response
START RUNNING / IDLE Enables automatic object detection if calibrated. MACHINE:STARTED followed by MACHINE:IDLE
STOP SAFE / LOCKED Suspends detection, moves all 6 servos to 10° via makeSafe(). MACHINE:STOPPED
RESET SAFE / IDLE Resets detection counters and secures all gates. RESET:OK
CALIBRATE CALIBRATING Re-baselines all 8 ultrasonic empty distances and HX711 tare. CALIBRATION:REMOVE_OBJECTS ... CALIBRATION:OK
STATUS ANY Queries current operating state, empty cm distances, and sensors. STATUS:<STATE>;PLASTIC_CM:...;PAPER_SCALE:READY

MAINTENANCE Preventive Care & Fault Isolation Matrix

Error Telemetry Root Cause Automated Firmware Action Field Technician Solution
ERROR:CALIBRATION_FAILED Object in chute or unplugged ultrasonic sensor. Aborts start; stays in safe mode. Empty chutes, inspect sensor plugs, send CALIBRATE.
ERROR:PLASTIC_ARRIVAL_TIMEOUT Bottle failed to reach bottom sensor within 5000ms. Closes iris servo (10°); resets count. Verify upper chute is clear; check servo 11 linkage.
ERROR:METAL_ARRIVAL_TIMEOUT Can failed to reach bottom sensor within 5000ms. Closes iris servo (10°); resets count. Check can flap and servo 27 travel.
ERROR:PAPER_WEIGHT_TIMEOUT Paper failed to exceed 20g threshold in 5000ms. Closes iris servo (10°); resets count. Ensure paper meets minimum mass (≥ 20g).
ERROR:CLEAR_TIMEOUT Chute sensor remains blocked 5000ms after drop gate. Closes drop gate; alerts attendant. Empty full storage bin; check for stuck container.
ERROR:PAPER_SCALE_NOT_READY HX711 DOUT pin stuck HIGH for >1000ms. Disables paper chamber operation. Check HX711 VCC/GND wires on Pins 37 and 38.
