SOP-RVM-OPS-01

Daily Morning Startup & Pre-Flight Checklist

Frequency: Daily 07:00 AM Role: Caretaker / Tech
  • Verify AC 220V UPS voltage is stable and surge protector green.
  • Power on lower cabinet rocker switch; allow Windows IoT to boot.
  • Confirm PowerShell `launch-kiosk.ps1` initializes dual displays without taskbar.
  • Check diagnostics bar: `SERIAL: CONNECTED 🟢`, `DB: OK 🟢`, `API: ONLINE 🟢`.
  • Execute test cycle: Press `0`, insert clean test bottle, claim test wallet points.
SOP-RVM-OPS-02

Public Citizen Operation & Material Rules

Frequency: Continuous Role: Citizen Facilitator
  • Accepted: Clean PET bottles (0.2L - 2.5L), Aluminium Cans, Paper Cups/UBC.
  • Prohibited: Glass, oil/bleach containers, filled liquid bottles, metal tins.
  • Ensure users insert containers one-by-one, bottom first, without crushing.
  • Validate Pakistani mobile format (`03xxxxxxxxx` - exactly 11 digits).
SOP-RVM-MAINT-03

Storage Bin Emptying & Level Sensor Reset

Frequency: At 85% Full Sensors: Pins D10 & D11
  • Press `888` + Admin PIN to pause public sessions.
  • Unlock bottom cabinet with master key; extract full 120L trolley liner.
  • Clean dust from Pin D10 (Plastic IR) and D11 (Can IR) level sensor lenses.
  • Insert fresh heavy-duty transparent collection liner; lock cabinet door.
  • In Admin Panel Tab 4, press "Reset Bin Full Counter".
SOP-RVM-MAINT-04

Chamber Optical Lens Cleaning & Calibration

Frequency: Weekly (Friday) Hotkey: "33"
  • Wipe Bottom (D2), Middle (D7), Top (D8) IR photoelectric lenses with 90%+ IPA.
  • Wipe inductive face plate (D5) and clean dust from ultrasonic cones (D3/D4).
  • Lubricate servo drop flap pivot hinge with dry silicone spray.
  • Press `33` on keypad to run 20-sample auto-calibration baseline.
SOP-RVM-NET-05

Offline Resiliency & Cloud Synchronization

Trigger: Network Outage Service: CentralSyncService
  • When 4G router disconnects, API dot shows Amber; recycling remains 100% operational.
  • Transactions written to local SQL Server `dbo.Transactions` with `IsSynced = 0`.
  • Upon network restoration, service auto-flushes FIFO queue in batches of 25 records.
  • Technician force override: Admin Window Tab 3 -> "Sync Pending Transactions".
SOP-RVM-SAFE-06

Emergency Jam Clearance & Safety Shutdown

Trigger: Jam Alert / Obstruction Safety: PINCH HAZARD
  • Immediately hit Red Emergency Stop Mushroom Button on kiosk side.
  • Unlock upper chamber access panel with maintenance key.
  • Using safety tongs or gloves, extract stuck container or foreign object.
  • Inspect sensor optical pathways for scratches or physical displacement.
  • Rotate E-Stop clockwise to release and reboot system.

ARDUINO UNO R3 INDUSTRIAL PINOUT ASSIGNMENTS

Pin Direction Hardware Subsystem Electronic Specification & Function
D2 INPUT Bottom IR Photoelectric Sensor Detects container entrance & base presence. Triggers scan timer.
D3 OUTPUT Ultrasonic Distance Sensor (Trig) Transmits 40 kHz acoustic burst to measure container drop & length.
D4 INPUT Ultrasonic Distance Sensor (Echo) Receives reflected echo; measures microsecond pulse width.
D5 INPUT Inductive Proximity Sensor HIGH = Ferrous/Aluminium Metal Can. LOW = PET Plastic / Paper.
D7 INPUT Middle IR Photoelectric Sensor Determines Medium height profile (> 18 cm threshold).
D8 INPUT Top IR Photoelectric Sensor Determines Large bottle profile (> 26 cm threshold).
D9 OUTPUT High-Torque Drop Gate Servo (PWM) 0° = Closed Gate, 90° = Drop Open into collection bin.
D10 INPUT Plastic Bin Level Optical Sensor Infrared beam at bin rim. LOW = Storage Bin Full Alert.
D11 INPUT Can/Metal Bin Level Optical Sensor Infrared beam at metal bin rim. LOW = Can Bin Full Alert.
D13 OUTPUT Internal Chamber LED Ring Illuminates scanning chamber during active container intake.
