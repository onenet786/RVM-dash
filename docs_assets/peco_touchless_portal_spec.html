PecoDrop Touchless Web Portal Architecture

The Touchless Web Portal enables corporate employees and public citizens to operate Reverse Vending Machines (RVM) and PecoDrop kiosks directly from their smartphone browser—eliminating physical touch requirements on kiosk screens or keypads while ensuring real-time container tracking, instant point rewards, and touchless perk redemptions.

📍 End-to-End Operational Workflow
01

QR Handshake

Kiosk display generates a dynamic encrypted QR code containing machine ID and session start token.

02

Mobile Activation

User scans QR code with mobile camera. Touchless portal activates instantly on phone browser.

03

Identity Auth

Auto-detects corporate domain emails (e.g., @engro.com) or verified phone numbers.

04

Intake Unlocking

Kiosk unlocks physical apertures (⭕ Plastic, 🔺 Cans, 🟦 Paper load cell) and enters active mode.

05

Live Telemetry

Web portal polls status every 1.5s, displaying real-time items deposited and points earned.

06

Remote Finish

User taps FINISH & CLAIM POINTS on phone or keypad. Session completes & credits PostgreSQL.
